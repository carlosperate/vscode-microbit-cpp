# Licences of everything this extension ships

The extension's own code is MIT, see [LICENSE](LICENSE). It carries a compiler,
its libraries and CODAL, each under its own terms. Every component's own notice
ships inside the extension under `dist/licenses/`, and this page says which is
which.

## The compiler: `dist/assets/toolchain/llvm.core.wasm` and the three small modules beside it

Clang, LLD and the LLVM binutils, compiled to WebAssembly from
[`arm/arm-toolchain`](https://github.com/arm/arm-toolchain) at an Arm Toolchain
for Embedded release. **Apache-2.0 with LLVM-exception**, the text in
`dist/licenses/toolchain/LICENSE.txt`. Packaged as
[`microbit-clang-wasm`](https://github.com/carlosperate/microbit-clang-wasm),
whose own description of its parts is `dist/licenses/toolchain/LICENSES`.

## The C and C++ libraries: `dist/assets/toolchain/llvm-resources.tar`

Arm Toolchain for Embedded's newlib-nano, libgloss, libc++, libc++abi,
libunwind and compiler-rt for the micro:bit's Cortex-M4, plus the Clang builtin
headers. libc++, libc++abi, libunwind and compiler-rt are **Apache-2.0 with
LLVM-exception**; newlib and libgloss carry their own collections of
**BSD-style notices**. Arm's notice set for exactly this variant is in
`dist/licenses/toolchain/sysroot/`:

- `COPYING.NEWLIB`, `COPYING.LIBGLOSS`
- `LLVM-LICENSE.txt`, `CLANG-LICENSE.txt`, `LLD-LICENSE.txt`, `COMPILER-RT-LICENSE.txt`
- `LIBCXX-LICENSE.txt`, `LIBCXXABI-LICENSE.txt`, `LIBUNWIND-LICENSE.txt`
- `THIRD-PARTY-LICENSES.txt`, Arm's index of the above

## The JavaScript that runs the compiler

Inside `dist/worker.browser.js` and `dist/worker.node.mjs`: the runtime derived
from [YoWASP/clang](https://codeberg.org/YoWASP/clang) and
[`@yowasp/runtime`](https://www.npmjs.com/package/@yowasp/runtime) by Catherine
(whitequark), both **ISC**, and the glue generated by
[jco](https://github.com/bytecodealliance/jco). Described in
`dist/licenses/toolchain/LICENSES`.

## CODAL: `dist/assets/codal/payload.tar`

[codal-core](https://github.com/lancaster-university/codal-core),
[codal-nrf52](https://github.com/lancaster-university/codal-nrf52) and
[codal-microbit-v2](https://github.com/lancaster-university/codal-microbit-v2)
by Lancaster University and the Micro:bit Educational Foundation: **MIT**,
sources, headers and the archives built from them. Each library's `LICENSE`
travels inside the payload, and `dist/licenses/codal/LICENSES` is the CODAL
package's own description, with the paths.

## Nordic Semiconductor: inside the same payload

The nRF5 SDK sources in
[codal-microbit-nrf5sdk](https://github.com/lancaster-university/codal-microbit-nrf5sdk),
and the SoftDevice, MBR, bootloader, settings and UICR objects the build links,
are Nordic Semiconductor's. **Their licence permits use only with Nordic
Semiconductor integrated circuits**, which the BBC micro:bit V2 uses. The text
is `codal/libraries/codal-microbit-nrf5sdk/LICENCE.txt` inside the payload.
